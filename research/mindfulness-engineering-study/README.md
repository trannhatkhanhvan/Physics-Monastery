# Mindfulness and Engineering Problem Solving Study

This workspace organizes the quantitative phase of the study on undergraduate engineering students, mindfulness traits, and engineering performance.

## Research question

Are cultivated mindfulness traits associated with academic performance and problem-solving behavior in undergraduate engineering students?

## Workflow

Raw Data
  -> Codebook
  -> Cleaned Analysis Dataset
  -> Derived Scores
  -> Exploratory Analysis
  -> Public Website Outputs

## Privacy rule

Raw student data must remain private.

Do not commit:

- raw Excel files,
- A-numbers,
- grade screenshot metadata,
- row-level identifiable data,
- private duplicate reports,
- private cleaning notes containing identifiers.

The public website should use only aggregate, de-identified outputs from:

outputs/public/
